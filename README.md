# Prodig book layout

## Run preview

```bash
node dev-server.mjs
```

Open:

```text
http://localhost:8000/examples/book.html
```

## Structure

- `assets/css/buku-layout.css` — layout engine
- `examples/modules/` — modular content chunks
- `examples/book.html` — browser preview loader
- `docs/book_map.md` — flow map
